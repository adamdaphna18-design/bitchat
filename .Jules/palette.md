## 2024-06-29 - VoiceNoteView and WaveformView Accessibility Integration
**Learning:** Custom interactive media views in SwiftUI (e.g., using `Canvas`, `ZStack`, or raw gestures) are not automatically interpreted by VoiceOver. Additionally, applying `.accessibilityElement(children: .ignore)` or an `.accessibilityLabel` to a parent container that contains interactive controls (like a cancel button) completely breaks interaction because it strips the inner buttons from the accessibility tree.
**Action:** When making custom media controls (like a scrubbable waveform) accessible, apply `.accessibilityElement(children: .ignore)` only to the specific visual element (e.g., the waveform container) and use `.accessibilityAdjustableAction` for interactivity. Ensure that standalone icon-only buttons (like play/pause and cancel) explicitly receive dynamic `.accessibilityLabel` modifiers, wrapped in `String(localized:comment:)`, to maintain functional VoiceOver support.
