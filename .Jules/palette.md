## 2024-05-18 - Making Custom Interactive Media Views Accessible
**Learning:** Custom purely visual SwiftUI components with raw `DragGesture` like `WaveformView` are entirely opaque to VoiceOver. Applying `.accessibilityElement(children: .ignore)` on the view allows us to attach `.accessibilityLabel`, `.accessibilityValue`, and most importantly `.accessibilityAdjustableAction` so VoiceOver users can interactively scrub the playback position with swipes, bypassing the `DragGesture`. However, we must ensure these modifiers are applied on the correct specific components (e.g. `WaveformView`) rather than parent containers with other interactive elements (e.g. `VoiceNoteView`), as applying it to the parent would strip out sibling buttons (like play/pause and cancel) from the accessibility tree.
**Action:** When implementing custom visual gestures (Canvas + DragGesture), isolate the view and explicitly add `.accessibilityElement(children: .ignore)` followed by `.accessibilityLabel` and `.accessibilityAdjustableAction` to ensure functional parity for screen readers, and dynamically update accessibility labels for any stateful icon-only sibling buttons.
