## 2024-05-18 - Added Accessibility Labels to Voice Note View and Image Preview Cancel Buttons
**Learning:** Icon-only buttons (like the Play/Pause and Cancel buttons in media messages) require dynamic `.accessibilityLabel` modifiers to ensure VoiceOver properly reads out their state. When using custom audio waveforms in SwiftUI, adding `.accessibilityElement(children: .ignore)` followed by an `.accessibilityLabel` and `.accessibilityValue` prevents VoiceOver from announcing useless visual layout data and instead provides meaningful playback progress.
**Action:** When creating new custom controls or icon-only interactive elements in SwiftUI, always attach explicit, dynamic `.accessibilityLabel` modifiers. For complex custom graphics (like the audio waveform Canvas), group them into a single accessible element and provide a summarized `.accessibilityValue`.
