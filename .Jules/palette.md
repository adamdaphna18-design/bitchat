## 2024-05-14 - Custom Media Controls and Accessibility
**Learning:** Custom interactive media views (like WaveformView, VoiceNoteView, and BlockRevealImageView) heavily rely on non-standard SwiftUI patterns (Canvas, Gestures on generic views, raw ZStacks) which VoiceOver cannot interpret automatically. Specifically, icon-only cancellation/play buttons lose their context without text, and gesture-driven scrubbing (like in the audio waveform) is completely opaque to screen readers unless explicitly bridged.
**Action:** When creating or modifying custom media components, always manually bridge the visual interaction to VoiceOver. For buttons, this means explicit `.accessibilityLabel` modifiers on the generic `Button` or `Image` wrappers. For gesture-driven data visualizations (like waveforms), group the container with `.accessibilityElement(children: .ignore)`, assign it an `.accessibilityLabel` and `.accessibilityValue`, and provide an `.accessibilityAdjustableAction` so VoiceOver users can emulate the swipe gestures using native system interactions (swipe up/down).
