## 2024-05-18 - Dynamic UI Accessibility Labels
**Learning:** For dynamic components like the playback button that changes icon and state depending on whether it is playing or paused, VoiceOver needs the \`.accessibilityLabel\` to explicitly interpolate the dynamic string based on the same state rather than relying on the image symbol name. For visual-only elements representing information (like a waveform), it is necessary to apply \`.accessibilityElement(children: .ignore)\` and an overarching \`.accessibilityLabel\` so it can properly be announced.
**Action:** When adding accessibility for interactive toggle buttons with dynamic visual states, provide a dynamic \`String(localized:)\` based on state. When grouping custom drawing components (like WaveformView) in a larger layout, hide their drawing elements from VoiceOver and label the container.
