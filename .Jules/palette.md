## 2024-05-22 - Accessibility Labels on Icon-Only Media Buttons
**Learning:** Custom media components in SwiftUI (like VoiceNoteView and BlockRevealImageView) often use icon-only buttons for play, pause, and cancel actions which VoiceOver cannot interpret accurately by default. However, when these buttons are placed inside parent containers, applying modifiers like `.accessibilityElement(children: .ignore)` or implicitly grouping them by adding an `.accessibilityLabel` directly to the parent container will actively strip the children from the accessibility tree, rendering the buttons completely inaccessible.
**Action:** Always add `.accessibilityLabel` to icon-only interactive elements. Crucially, *do not* use `.accessibilityElement(children: .ignore)` or implicitly group parent containers if they contain interactive controls, unless you intend to manually forward `.accessibilityAction` modifiers. Allow VoiceOver to naturally discover the interactive children instead.
