## 2025-02-18 - Dynamic Accessibility for VoiceNoteView
**Learning:** For custom pure-visual SwiftUI components like Waveform views, using \`.accessibilityElement(children: .ignore)\` combined with \`.accessibilityLabel\` and dynamic \`.accessibilityValue\` is an effective way to expose continuous progress without confusing VoiceOver. When button contents change dynamically based on state (e.g. Play/Pause toggle), the accessibility label must dynamically update as well to reflect the current state action.
**Action:** Always group visual elements (like waveforms) with a single accessibility wrapper instead of letting VoiceOver infer contents. Always use dynamic \`String(localized: ...)\` tags on icon-only toggle buttons so their labels are correct and extractable to String Catalogs.
